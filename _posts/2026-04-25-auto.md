## auto

### （1）auto的定义

auto的原理就是根据初始化的表达式，在**编译期间**根据表达式类型自动推导出对象的类型。

auto的作用就是为了简化变量初始化，如果这个变量有初始化表达式，就可以用auto代替类型声明。例如`auto x1 = 5;` 等价于 `int x1 = 5;`

### （2）auto的注意事项

1. 用auto声明的变量**必须初始化**
2. 函数和模板参数不能被声明为auto
3. 因为auto是一个占位符，并不是一个他自己的类型，因此不能用于**类型转换**或其他一些操作，如`sizeof`和`typeid`
4. 定义在一个auto序列的变量必须始终推导成同一类型
`auto x1 = 5,x2 = 5.0,x3='r'; //这样写是不合法的，因为各个变量类型不同`

> 如果编译期间编译器已经得知auto声明变量的类型，那么该变量可以进行类型转换、sizeof等操作。我们上文提到的是绝不能有“sizeof(auto)”这种写法。
> 

#### 注意：普通的 auto 会自动丢弃引用属性！

```cpp
int a = 10;
int& ref_a = a;

auto b = ref_a;  // b 的类型是 int，而不是 int&。b 只是复制了 a 的值！
b = 20;          // a 的值依然是 10

// 如果你想推导为引用，必须显式写出 &：
auto& c = ref_a; // c 的类型是 int&
c = 30;          // a 的值变成了 30
```

#### 总结：

• 想要拷贝一份独立的数据：用 auto
• 想要修改原数据：用 auto&
• 想要只读观察原数据（且避免拷贝开销）：用 const auto&

### （3）当auto遇上const

<aside>
🗯️

auto 的推导规则取决于你是“**传值**”还是“**传引用/指针**”。

在这里，我们需要区分一下“**顶层 const**”（对象本身是常量，不可改）和“**底层 const**”（指针指向的对象是常量，不可通过指针改）。

</aside>

#### a. 按值推导（会丢弃顶层`const`）

当你使用普通的 `auto` 时，相当于**按值拷贝**。既然是拷贝出一个全新的独立对象，原对象的 `const` 属性对新对象就没有意义了，因此**编译器会忽略原对象的顶层 `const`**。

```cpp
const int a = 10;
auto b = a;       // b 的类型是 int（丢弃了 const）
b = 20;           // 成功！b 是一个普通的 int

// 如果你希望 b 也是常量，必须显式加上 const：
const auto c = a; // c 的类型是 const int
```

#### b. 按引用推导（会保留`const`）

当你使用 `auto&` 时，你是给原对象**起别名**，这时候**必须保留原对象的 const 属性**，否则就会导致可以通过普通引用修改常量，这在 C++ 中是严禁的。

```cpp
const int a = 10;
auto& d = a;      // d 的类型是 const int&（保留了 const）
// d = 20;        // 编译错误：不能通过常量引用修改值
```

#### c. 指针与推导（丢弃顶层，保留底层）

```cpp
int x = 10;
const int* p1 = &x;       // 底层 const（指针指向的内容不可变）
auto p2 = p1;             // p2 是 const int*（底层 const 被保留）

int* const p3 = &x;       // 顶层 const（指针本身的指向不可变）
auto p4 = p3;             // p4 是 int*（顶层 const 被丢弃）
```

### （4）什么情况下使用 `auto` 是不合法的？

虽然 `auto` 很好用，但在以下场景中编译器会直接报错：

#### ❌ 1. 声明时不初始化

`auto` 的原理是靠等号右边的值来推导类型。如果不给初始值，编译器就无从下手。

`// auto x;      // 编译错误：未初始化
auto x = 0;     // 合法：x 是 int`

#### ❌ 2. 用于类的非静态成员变量

类在实例化之前，编译器需要知道对象的确切内存大小。不能在类内部用 `auto` 来声明普通的成员变量。

`class MyClass {
    // auto val = 10; // 编译错误
    int val = 10;     // 合法
};`

#### ❌ 3. 用于定义传统的 C 风格数组

你不能用 `auto` 直接加上 `[]` 来推导数组。

`// auto arr[] = {1, 2, 3}; // 编译错误

// 正确做法之一：推导为 std::initializer_list
auto arr2 = {1, 2, 3}; // arr2 的类型是 std::initializer_list<int>

// 正确做法之二：使用 std::array (C++17 支持类模板参数推导)
std::array arr3 = {1, 2, 3};`

#### ❌ 4. 作为模板实例化的具体类型参数

实例化模板时，不能拿 `auto` 充当具体的类型。

`// std::vector<auto> vec; // 编译错误`
