# 引用 &

## 1. 引用的概念

>>声明具名的变量引用，即既存对象或函数的别名。

>>引用名特点：使用时类似变量，作为参数时能传引用。

>>引用的注意事项：必须初始化；不可重绑定（即不能再指向其他变量）；不能为空

## 2. 引用不是对象

——引用**并不开辟新的存储空间**来存放数据，而是直接绑定到原有变量的内存地址上。

（在某些特定情况（如类成员变量中的引用、数组中的引用），编译器为了实现“不可重绑定”的特性，可能会在底层用一个常量指针（int* const）来实现引用，这时它会占用内存。但在局部变量这种常见场景下，它通常被优化为直接别名，不占额外空间。）

——因为引用不是对象，故：
**• 不存在引用的数组
• 不存在指向引用的指针
• 不存在引用的引用
• C++不存在引用为空的概念，即引用必须被定义**

## 3. 引用的本质

```latex
a:变量 p:指针 r:引用

0x1000        [ a ]       | 10 |                原始整型变量，存数值 10
^
| (a 的地址是 0x1000)
|

^
| (p 本身占用内存，存的是地址)
|
(无新地址)    [ r ]       (无独立存储)          引用 r 不占用新内存空间
^         (逻辑上直接映射)      编译器看到 r 时，直接替换为 a
|
+---------+--------------------+
|
v
实际访问的是 0x1000 处的值 (10)
```

## 4. 指针和引用

>>相同：可以使一个函数向调用者返回多个数值。
>>不同：原理不同。引用传递中，**形参、实参实质为同一变量**，或者说是为某个变量起多了一个名字。而使用指针作函数参数，则是使被调用函数获得**某变量的地址**，从而使用这个地址访问这个变量。**指针有null值，引用无**。
>>从返回值的角度看，引用形参比利用指针方便。

| 特性 | 引用 (Reference) | 指针 (Pointer) |
| --- | --- | --- |
| 本质 | 变量的别名 | 存放地址的变量 |
| 内存占用 | 通常不占用（视为别名） | 占用内存 (4/8 字节) |
| 初始化 | 必须初始化 | 可以不初始化 (虽危险但合法) |
| 可变性 | 绑定后不可改变指向 | 可以随时改变指向 |
| 空值 | 不能有 `nullptr` | 可以为 `nullptr` |
| 运算 | 不支持指针算术 (`r++` 是值加 1) | 支持指针算术 (`p++` 地址加 1) |
| 底层实现 | 语法糖 (通常) | 真实的内存地址存储 |

## 5. 不能返回局部变量的引用！

——函数结束时，局部变量就被销毁了，你返回的“别名”指向的是一块已经无效的内存。

```cpp
double& f(double x){
    double y; //大错特错！！！  -->> **static double y**  正确！
    /*static 变量存储在静态存储区（全局数据区），生命周期贯穿整个程序运行期，不会随函数结束而销毁。*/
    y=sin(x);
    return y;
}

//返回动态开辟
int& getHeapReference() {
    int* p = new int(10);
    return *p; // 安全：内存在堆上，直到 delete 前都有效
}
// 调用者必须负责 delete，否则内存泄漏。
// 现代 C++ 更推荐使用 std::unique_ptr 或 std::shared_ptr 管理堆内存，而不是裸指针/引用。
```

## 6. 引用作为函数的返回值

| 特性 | 返回值 (Return by Value) | 返回引用 (Return by Reference) |
| --- | --- | --- |
| 主要用途 | 返回计算结果、临时对象 | 1. 实现左值赋值 (如 `arr[i]=x`)  2. 避免大对象拷贝 |
| 能否被赋值 | ❌ 不能 (`func() = 5` 非法) | ✅ 能 (`func() = 5` 合法) |
| 性能 | 涉及拷贝（C++11 后可移动优化） | 零拷贝，最高效 |
| 安全性 | 高（独立副本，互不影响） | 中（调用者可直接修改源数据，需小心生命周期） |
| 典型应用 | 数学运算 `a + b` | 运算符重载 `operator[]`, `operator<<`, `Getter` |

——“零拷贝”？当函数需要返回一个很大的对象（如大型结构体、长字符串、复杂容器）时，**按值返回会触发拷贝构造函数**，消耗大量的 CPU 时间和内存。 返回引用可以直接返回内部已有对象的别名，**零拷贝**。

——允许**“链式赋值”**或**“修改返回值”**
